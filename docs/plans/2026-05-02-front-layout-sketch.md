## 全局外壳：FrontLayout

所有前台页面（除登录/注册）共用同一外壳布局。

```
+--------------------------------------------------------------+
| [Logo] 博客    首页 | 大厅 | 频道 | AI助手   [搜索框]   通知 头像 |
+--------------------------------------------------------------+
|                                                              |
|                     <router-view />                          |
|                                                              |
+--------------------------------------------------------------+
|                    页脚 · 版权信息                             |
+--------------------------------------------------------------+
```

**顶部导航栏** (sticky, h=60px)
- 左：Logo + 站名
- 中：主导航链接 + 搜索框
- 右：通知角标（登录后）+ 用户头像下拉菜单（登录后）/ 登录注册按钮（未登录）

**通知下拉面板**（类 GitHub）：点击通知图标弹出下拉面板，显示最近 5-10 条通知摘要，底部有「查看全部」跳转通知中心。面板内可快速标记已读。角标数字显示未读数。

**用户下拉菜单**：个人中心、我的收藏、我的足迹、我的文件、我的系列、消息、退出登录

**左侧悬浮操作栏**（竖排，sticky）：固定在内容区左侧，竖向排列图标按钮（点赞、收藏、分享、回到顶部），滚动时始终可见，不遮挡正文内容
**评论区**：评论输入框 + 树形评论列表，支持回复、点赞、删除
**特殊状态**：密码保护文章弹出密码输入弹窗

**输入框**：支持文本输入 + 文件/图片上传 + 回复引用预览

## 附录：响应式策略

### 断点定义

| 断点 | 宽度 | 目标设备 |
|------|------|----------|
| sm | < 768px | 手机竖屏 |
| md | 768px - 1024px | 平板 / 小屏笔记本 |
| lg | > 1024px | 桌面端（默认） |

### 各布局模式响应式方案

| 布局模式 | 桌面端 (lg) | 平板 (md) | 手机 (sm) |
|---------|------------|-----------|----------|
| **三栏**（首页） | 三栏完整展示 | 左栏隐藏 → 汉堡按钮触发抽屉；右栏折叠到底部 | 仅中栏，左栏抽屉，右栏隐藏 |
| **两栏-主侧**（文章详情） | 主栏 + 侧栏 | 侧栏折叠到底部 | 侧栏隐藏，TOC 收入顶部浮动按钮 |
| **两栏-主从**（聊天） | 三栏完整展示 | 右栏隐藏 → 点击群信息弹出抽屉 | 仅显示会话列表 / 消息区，通过导航切换 |
| **单栏** | 居中最大宽度 ~900px | 自适应宽度 | 全宽，减少内边距 |
| **居中卡片** | 固定宽度卡片 | 卡片自适应 | 全宽卡片，减少内边距 |

### 导航栏响应式

- **lg**：完整导航链接 + 搜索框 + 通知 + 头像
- **md**：导航链接收缩为「更多」下拉，搜索框保留
- **sm**：仅保留 Logo + 汉堡按钮（展开侧边抽屉导航）+ 通知 + 头像

## 附录：布局模式总结

前台页面可归纳为以下布局模式：

| 模式 | 适用页面 | 特征 |
|------|---------|------|
| **居中卡片** | 登录、注册、关于 | 独立页面/居中内容卡片 |
| **三栏** | 首页 | 左侧边栏 + 中间主内容 + 右侧边栏 |
| **两栏-主侧** | 文章详情、AI助手 | 主内容区 + 侧边栏 |
| **两栏-主从** | 收藏、聊天 | 主面板 + 从面板 |
| **单栏-列表** | 足迹、系列列表、申请页面 | 工具栏 + 内容列表/表单 |
| **单栏-卡片** | 通知中心、频道列表 | 筛选/操作栏 + 卡片列表 |
| **单栏-表单** | 账号设置、通知设置 | Tab 切换 + 表单/开关列表 |
| **单栏-信息** | 个人中心、用户主页 | 顶部信息卡片 + Tab 内容区 |
| **网格** | 文件、友情链接 | 工具栏 + 卡片网格 |
