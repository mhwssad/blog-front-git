## 错误码速查

### 认证相关（401xx）

| code | 说明 |
|-----|------|
| 40101 | 用户名或密码错误 |
| 40102 | 未登录或登录已过期 |
| 40104 | 账号已锁定 |
| 40105 | 账号已禁用 |
| 40108 | 无效的令牌 |
| 40112 | 邮箱验证码错误 |
| 40113 | 邮箱验证码已过期 |
| 40115 | 发送验证码过于频繁 |
| 40130 | 原密码错误 |

### 参数校验（400xx）

| code | 说明 |
|-----|------|
| 40001 | 参数校验失败 |

### 权限相关（403xx）

| code | 说明 |
|-----|------|
| 40300 | 没有访问权限 |
| 40304 | 仅超级管理员可执行此操作 |
