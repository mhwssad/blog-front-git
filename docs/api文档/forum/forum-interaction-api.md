# 论坛互动接口

> 统一响应格式、分页约定、错误码见 [README.md](../README.md#联调统一约定)

包含帖子点赞、收藏、频道分享相关接口。以下接口均要求登录。

---

## 点赞帖子

**接口信息**

- 路径：`POST /api/user/forum/posts/{postId}/likes`
- 鉴权：是
- 说明：点赞指定帖子，幂等操作

**响应示例**

```json
{
  "code": 200,
  "message": "成功",
  "timestamp": "2025-01-15T13:30:00",
  "data": null
}
```

**错误码**

| code | 说明 |
|-----|------|
| 40401 | 帖子不存在 |
| 40011 | 帖子已删除/隐藏 |
| 40011 | 用户被禁言 |
| 40101 | 未登录 |
| 50001 | 系统异常 |

## 收藏帖子

**接口信息**

- 路径：`POST /api/user/forum/posts/{postId}/collections`
- 鉴权：是
- 说明：收藏指定帖子到收藏夹，不指定folderId时使用默认论坛收藏夹

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| `folderId` | Long | 否 | 收藏夹ID，不传则使用默认论坛收藏夹 |
| `remark` | String | 否 | 收藏备注 |

**响应示例**

```json
{
  "code": 200,
  "message": "成功",
  "timestamp": "2025-01-15T14:30:00",
  "data": null
}
```

**错误码**

| code | 说明 |
|-----|------|
| 40011 | 收藏夹不存在 |
| 40401 | 帖子不存在 |
| 40011 | 帖子已删除/隐藏 |
| 40011 | 用户被禁言 |
| 40101 | 未登录 |
| 50001 | 系统异常 |

## 频道分享

### 分享帖子到频道

**接口信息**

- 路径：`POST /api/user/forum/posts/{postId}/channel-share`
- 鉴权：是
- 说明：将帖子分享到指定频道，每个帖子同一时间只能挂接一个频道

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| `conversationId` | Long | 是 | 目标频道会话ID |

**响应示例**

```json
{
  "code": 200,
  "message": "成功",
  "timestamp": "2025-01-15T15:30:00",
  "data": {
    "id": 5,
    "forumPostId": 10,
    "conversationId": 99,
    "channelName": "技术交流频道",
    "linkType": "forum_share",
    "linkedBy": 100,
    "linkedAt": "2025-01-15T15:30:00"
  }
}
```

**错误码**

| code | 说明 |
|-----|------|
| 40011 | 参数校验失败 |
| 40401 | 帖子不存在 |
| 40011 | 帖子未发布 |
| 40011 | 用户被禁言 |
| 40011 | 用户不是频道成员 |
| 40101 | 未登录 |
| 50001 | 系统异常 |
