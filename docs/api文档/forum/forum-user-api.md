# 论坛用户侧接口索引

> 统一响应格式、分页约定、错误码见 [README.md](../README.md#联调统一约定)

本目录将论坛用户侧接口按功能拆分为以下聚焦文件：

| 文件 | 内容 |
|------|------|
| [forum-post-api.md](forum-post-api.md) | 论坛首页、版块列表、帖子查询/详情、发帖/编辑/删除 |
| [forum-reply-api.md](forum-reply-api.md) | 回复发表/编辑/删除 |
| [forum-interaction-api.md](forum-interaction-api.md) | 帖子点赞/取消点赞、收藏/取消收藏、频道分享 |
| [forum-my-posts-api.md](forum-my-posts-api.md) | 我的帖子列表/详情、帖子频道挂接 CRUD |
