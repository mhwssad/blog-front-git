## 执行步骤

### Step 1：创建前台布局组件

创建 `src/layouts/FrontLayout.vue`，包含：
- 顶部导航栏（Logo、搜索框、用户头像/登录按钮、通知角标）
- `<router-view />` 主内容区

### Step 2：创建 8 个前台页面占位文件

每个页面包含：
- `<template>` 中放置页面标题和占位说明
- `<script setup lang="ts">` 中导入必要依赖
- `<style scoped>` 基础样式
- 组件拆分建议（来自文档）

### Step 3：更新路由配置

修改 `src/router/fixed-routes.ts`：
- 引入 `FrontLayout` 作为前台页面公共父路由
- 首页 `/` → FrontLayout 子路由
- 新增 8 个前台页面路由
- 登录 `/login`、注册 `/register` 保持独立
- 修改 `src/router/index.ts` 引入新路由结构

### Step 4：验证

- `pnpm type-check` 通过
- `pnpm build` 通过
