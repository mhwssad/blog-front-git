- Users、Roles、Tags 从 `useTableHeight` 迁移到 `useContentAdmin`，复用统一的响应式表格和分页布局
- Roles 状态切换改为 `v-permission.disable`，与其他模块权限方式对齐
- 删除确认文本统一为 `确定要删除{类型}"${name}" 吗？` 格式（Categories、Tags、Collections、Comments、Interactions、Footprints、Files）
- Comments 的 CommentDetailDialog 从 `v-model` 改为 `v-model:visible`
- 所有模块 `handleSizeChange` 统一重置 `current = 1`
- Interactions 分页改为双向绑定
- CSS 命名统一为 `{module}-management-page` 模式
- 分页对齐统一为居中
- type-check 和 build 验证通过
