# 提取 12 个通用组件到 src/components/common/

## Context

admin 目录 36 个列表页面有大量重复代码：相同的 el-table+el-pagination 布局、搜索表单、FormDialog/DetailDialog 结构、状态切换、操作列、确认弹窗等。重复 CSS 类（`.table-actions`、`.pagination`、`.card-header`、`.filter-item`）在 25+ 文件中复制。目标：提取 12 个通用组件 + 1 个 composable，减少约 2000 行重复代码。

## 实施计划

### 阶段 1：独立原子组件（无依赖）

#### 1. EmptyState.vue
- 封装 `el-empty`，默认 `imageSize: 100`、`description: '暂无数据'`
- Props: `description`, `imageSize`
- Slots: `default`（操作按钮区域）

#### 2. UserCell.vue
- 封装 `el-avatar` + 昵称，头像 fallback 取 `nickname.charAt(0)`
- Props: `avatar?: string|null`, `nickname: string`, `size?: number`(36), `showName?: boolean`(true), `sub?: string`
- Slots: `default`（完全替换）, `name`（替换昵称渲染）

#### 3. StatusSwitch.vue
- 封装 `el-switch`，处理 `v-permission.disable`、loading 状态
- Props: `modelValue: number`, `activeValue`(1), `inactiveValue`(0), `activeText`('正常'), `inactiveText`('停用'), `permission?: string`, `loading?: boolean`
- Emits: `update:modelValue`, `change`
- 注意：异步逻辑由父组件控制，组件仅负责 UI 和状态切换

#### 4. ActionColumn.vue
- 封装 `el-table-column(label="操作")` + `.table-actions` CSS
- Props: `width`(160), `fixed`('right'), `align`('center'), `compact`(false)
- Slots: `default`（接收 `{ row, column, $index }`）

### 阶段 2：容器/包装器组件

#### 5. SearchFilter.vue
- 封装 `el-card(shadow="never")` + `el-form(inline)` + 展开/收起
- Props: `model`, `expanded`(v-model), `showExpand`(false)
- Emits: `update:expanded`, `search`, `reset`
- Slots: `default`（始终可见筛选项）, `expanded`（折叠项）, `actions`（覆盖按钮）
- 包含共享 CSS：`.search-card`, `.filter-item`, `.filter-control`, `.expand-icon`, 768px 响应式

#### 6. DataTable.vue
- 封装 `el-card` + `el-table` + `el-pagination` 的完整列表布局
- Props: `data`, `loading`, `total`, `currentPage`(v-model), `pageSize`(v-model), `pageSizes`, `paginationLayout`, `title`, `showCard`(true), `compact`(false), `border`(true), `stripe`(true), `tableLayout`('auto'), `rowKey`, `emptyText`, `emptyImageSize`
- Emits: `update:currentPage`, `update:pageSize`, `page-change`, `size-change`, `selection-change`, `sort-change` + 透传 el-table 事件
- Slots: `header`(标题), `header-extra`(右侧操作按钮), `toolbar`(表格上方), `default`(el-table 列), `empty`, `pagination-extra`
- 关键设计：使用 `v-bind="$attrs"` + `inheritAttrs: false` 透传属性到 el-table
- 包含共享 CSS：`.card-header`, `.pagination`, 响应式媒体查询

#### 7. FormDialog.vue
- 封装 `el-dialog` + 标题计算 + 页脚按钮（取消/确认）
- Props: `modelValue`, `title`, `addTitle`('新增'), `editTitle`('编辑'), `isEdit`, `width`('520px'), `confirmPermission`, `confirmText`('保存'), `closeOnClickModal`(false), `destroyOnClose`(true), `loading`(false)
- Emits: `update:modelValue`, `submit`, `cancel`
- Slots: `default`（表单内容）, `footer`（覆盖页脚）
- 关键设计：不拥有 `el-form`，父组件在 slot 中放置自己的 `el-form`。组件仅管理对话框外壳和页脚按钮

#### 8. DetailDialog.vue
- 封装 `el-dialog` + 详情展示 + 关闭按钮
- Props: `modelValue`, `title`, `detail`(any|null), `width`('520px'), `destroyOnClose`(true), `loading`(false)
- Emits: `update:modelValue`
- Slots: `default`（接收 `{ detail }`）, `empty`, `footer`

### 阶段 3：实用工具/可选组件

#### 9. BatchToolbar.vue
- 封装批量操作栏，`transition="el-fade-in"` 动画
- Props: `selectedCount`
- Slots: `default`（操作按钮）

#### 10. ImagePreview.vue
- 封装 `el-image` + 预览
- Props: `src`, `previewSrcList`(默认 [src]), `fit`('cover'), `width`(60), `height`(60), `lazy`(true)

#### 11. CodeBlock.vue
- 代码块展示 + 复制按钮（无高亮库，后续可加）
- Props: `code`, `language`, `showCopy`(true), `maxHeight`('400px')
- Slots: `default`（备选代码内容）

#### 12. useConfirm composable
- 放置在 `src/composables/useConfirm.ts`（非组件）
- 封装 `ElMessageBox.confirm`，保持命令式风格
- API: `const { confirm } = useConfirm()` → `await confirm({ message, title?, type? })`
- 不创建 ConfirmDialog 组件，RiskConfirmDialog 继续用于危险操作

## 范围

**仅创建组件，不做现有页面迁移。** 后续按需逐步替换。

## 验证

1. 每批组件创建后运行 `pnpm type-check` 确保无类型错误
2. 全部完成后运行 `pnpm build` 确保构建通过
- 封装 `ElMessageBox.confirm` 的标准模式
- API: `const { confirm } = useConfirm()` → `await confirm({ message, title?, type? })`
- 返回 Promise，确认时 resolve，取消时 reject

## 约定

- 对话框使用 `modelValue` / `update:modelValue`（与 RiskConfirmDialog、ReportDialog 一致）
- `<script lang="ts" setup>` + `withDefaults(defineProps<{...}>(), {...})`
- 元组风格 `defineEmits<{...}>()`
- `<style scoped>` + BEM 命名
- `v-permission` / `v-permission.disable` 全局指令
